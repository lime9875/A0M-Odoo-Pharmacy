# A0M Pharma Systems - Odoo Enterprise Drug Inventory System

نظام متكامل ومطور لإدارة مخازن الأدوية والمستلزمات الطبية والشركات المصنعة بنمط **Odoo Enterprise v17 UI** باللغة العربية ودعم اتجاه RTL.

## المميزات الرئيسية:
- **تخصيص كامل للهوية التجارية باسم A0M**.
- **دليل تفصيلي لجميع الأشكال الدوائية والشركات والمستودعات**.
- **مؤشرات أداء وDashboard تفاعلية كلياً مع خريطة توزيع الأدوية**.
- **إدارات مخصصة لأذونات الصرف والإضافة والتحويلات الداخلية بين الفروع**.
- **واجهة مستخدم عصرية وسريعة الاستجابة متوافقة مع كل الأجهزة**.

## طريقة التشغيل:
1. قم بفك الضغط عن الملف ZIP.
2. افتح ملف `index.html` في أي متصفح ويب (Chrome, Firefox, Edge, Safari).
